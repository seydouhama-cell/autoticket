🛜 Configuration MikroTik (Walled Garden)

Autorisez l'accès gratuit à AutoTicket pour permettre à vos clients d'acheter des forfaits même sans connexion active.

🔍 Qu'est-ce que le Walled Garden ?

Cette configuration permet à un utilisateur connecté à votre WiFi (mais bloqué par le portail captif) d'accéder uniquement à AutoTicket et à la passerelle de paiement pour payer son ticket. Une fois son paiement validé, le routeur lui redonne un accès complet à Internet.

🔗 Lien du portail d'achat

Sélectionnez une zone pour obtenir son lien d'achat direct. Placez ce lien sur un bouton dans le fichier login.html de votre MikroTik.

📜 Script MikroTik - Walled Garden

# =====================================================================
# AUTOTICKET - WALLED GARDEN COMPLET
# Version : 2026-08-24
#
# Autorise avant authentification HotSpot :
# - AutoTicket
# - iPay
# - MyNITA
# - Amanata
# =====================================================================

# =====================================================================
# 1. NETTOYAGE DES REGLES IP EXISTANTES
# =====================================================================

/ip hotspot walled-garden ip remove [find where comment~"AutoTicket"]
/ip hotspot walled-garden ip remove [find where comment~"iPay"]
/ip hotspot walled-garden ip remove [find where comment~"MyNITA"]
/ip hotspot walled-garden ip remove [find where comment~"Amanata"]

:delay 2s

# =====================================================================
# 2. NETTOYAGE DES REGLES PAR DOMAINE
# =====================================================================

/ip hotspot walled-garden remove [find where dynamic=no and comment~"AutoTicket"]
/ip hotspot walled-garden remove [find where dynamic=no and comment~"iPay"]
/ip hotspot walled-garden remove [find where dynamic=no and comment~"MyNITA"]
/ip hotspot walled-garden remove [find where dynamic=no and comment~"Amanata"]

# =====================================================================
# 3. AUTOTICKET - DOMAINES
# =====================================================================

/ip hotspot walled-garden add dst-host="autoticket-pi.vercel.app" action=allow comment="AutoTicket Principal"
/ip hotspot walled-garden add dst-host="autoticket-ne.com" action=allow comment="AutoTicket Principal"
/ip hotspot walled-garden add dst-host="*.autoticket-ne.com" action=allow comment="AutoTicket Sous-domaines"

# =====================================================================
# 4. AUTOTICKET - BACKEND (Render)
# =====================================================================

/ip hotspot walled-garden add dst-host="autoticket-backend-ktsj.onrender.com" action=allow comment="AutoTicket Backend"

# =====================================================================
# 5. IPAY - DOMAINES PRINCIPAUX
# =====================================================================

/ip hotspot walled-garden add dst-host="i-pay.money" action=allow comment="iPay Principal"
/ip hotspot walled-garden add dst-host="*.i-pay.money" action=allow comment="iPay Sous-domaines"

# =====================================================================
# 6. IPAY - SERVEUR PRINCIPAL
# =====================================================================

/ip hotspot walled-garden ip add dst-address=34.204.115.196/32 protocol=tcp dst-port=80 action=accept comment="iPay HTTP"
/ip hotspot walled-garden ip add dst-address=34.204.115.196/32 protocol=tcp dst-port=443 action=accept comment="iPay HTTPS"

# =====================================================================
# 7. MYNITA - API DE VALIDATION
# =====================================================================

/ip hotspot walled-garden add dst-host="api.nitacashhub.com" action=allow comment="MyNITA API"

# =====================================================================
# 8. AMANATA - DOMAINE PRINCIPAL
# =====================================================================

/ip hotspot walled-garden add dst-host="amana-ta.com" action=allow comment="Amanata Principal"
/ip hotspot walled-garden add dst-host="*.amana-ta.com" action=allow comment="Amanata Sous-domaines"

# =====================================================================
# 9. AMANATA - SERVICES FIREBASE
# =====================================================================

/ip hotspot walled-garden add dst-host="securetoken.googleapis.com" action=allow comment="Amanata Firebase Auth"
/ip hotspot walled-garden add dst-host="firestore.googleapis.com" action=allow comment="Amanata Firestore"
/ip hotspot walled-garden add dst-host="firebaseremoteconfig.googleapis.com" action=allow comment="Amanata Firebase Config"

# =====================================================================
# CONFIGURATION TERMINEE
# =====================================================================

:put "✅ AutoTicket Walled Garden installe avec succes."
:put "✅ Services autorises : AutoTicket, iPay, MyNITA et Amanata."

📖 Comment appliquer ce script

1
📥 WinBox

Connectez-vous à votre routeur MikroTik à l'aide de l'outil WinBox.

2
💻 Nouveau Terminal

Dans le menu, cliquez sur New Terminal pour ouvrir la console.

3
📋 Coller & Valider

Collez le script dans le terminal et appuyez sur Entrée.
