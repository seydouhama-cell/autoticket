🛜 Configurer MikroTik

Connectez votre routeur à AutoTicket en 5 minutes
📌 Prérequis : Un routeur MikroTik avec HotSpot configuré. Ce script autorise l'accès à AutoTicket et iPay avant paiement.
1 Connectez-vous à votre routeur

Ouvrez WinBox ou connectez-vous en SSH à votre MikroTik.

2 Ouvrez le terminal

Dans WinBox, allez dans Terminal. En SSH, connectez-vous et tapez /terminal.

3 Copiez et collez le script ci-dessous

Collez le script dans le terminal et appuyez sur Entrée.

# ============================================================ # AUTOTICKET - CONFIGURATION WALLED GARDEN # Autorise AutoTicket et iPay avant authentification HotSpot # ============================================================ # 1. NETTOYAGE DES ANCIENNES RÈGLES /ip hotspot walled-garden remove [find comment~"AutoTicket|iPay"] /ip hotspot walled-garden ip remove [find comment~"AutoTicket|iPay"] # 2. AUTOTICKET - DOMAINES /ip hotspot walled-garden add dst-host="autoticket-ne.com" action=allow comment="AutoTicket Principal" add dst-host="*.autoticket-ne.com" action=allow comment="AutoTicket Sous-domaines" # 3. AUTOTICKET - VPS (31.207.34.201) /ip hotspot walled-garden ip add dst-address=31.207.34.201/32 protocol=tcp dst-port=80 action=accept comment="AutoTicket HTTP" add dst-address=31.207.34.201/32 protocol=tcp dst-port=443 action=accept comment="AutoTicket HTTPS" # 4. IPAY - DOMAINES /ip hotspot walled-garden add dst-host="i-pay.money" action=allow comment="iPay Principal" add dst-host="*.i-pay.money" action=allow comment="iPay Sous-domaines" # 5. IPAY - IP (34.204.115.196) /ip hotspot walled-garden ip add dst-address=34.204.115.196/32 protocol=tcp dst-port=80 action=accept comment="iPay HTTP" add dst-address=34.204.115.196/32 protocol=tcp dst-port=443 action=accept comment="iPay HTTPS" # ============================================================ # FIN DE LA CONFIGURATION # ============================================================
4 Vérifiez que tout fonctionne

Dans WinBox, allez dans IP → Hotspot → Walled Garden et vérifiez que les règles AutoTicket et iPay sont présentes.

🔧 Personnalisation : Si vous utilisez un autre domaine ou une autre IP, modifiez les lignes correspondantes dans le script.
